MOKI(모키) 개인정보처리방침

시행일: 2026-10-29

1. 수집하는 정보

MOKI는 개인정보를 수집하거나 외부 서버로 전송하지 않습니다. 회원가입, 광고, 분석 도구, 추적 기능이 없습니다.

2. 기기 안에만 저장되는 정보

  • 사용자가 등록한 물건의 이름, 이모지, 지정한 동작
  • 물건 등록 시 촬영한 작은 참조 사진과, 그 사진에서 계산한 이미지 특징값
  • 세션 시간, 횟수 기록

이 정보는 iPhone 안에만 저장됩니다. 앱을 삭제하거나 앱의 기록 → 모든 데이터 삭제를 실행하면 지워집니다.

3. 카메라 사용

카메라는 등록한 물건을 알아보는 용도로만 사용합니다. 카메라 영상은 기기 안에서 실시간으로 분석된 뒤 저장하지 않습니다. 등록할 때 직접 촬영 버튼을 누른 사진만 저장됩니다.

4. 알림

휴식 타이머가 끝났을 때 알려 주기 위해서만 기기 내 로컬 알림을 사용합니다.
