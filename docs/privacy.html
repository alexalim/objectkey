MOKI(모키) 개인정보처리방침

시행일: 2026-10-29

1. 수집하는 정보

MOKI는 개인정보를 수집하거나 외부 서버로 전송하지 않습니다. 회원가입, 광고, 분석 도구, 추적 기능이 없습니다.

2. 기기 안에만 저장되는 정보

  • 사용자가 등록한 물건의 이름, 이모지, 지정한 동작
  • 물건 등록 시 촬영한 작은 참조 사진과, 그 사진에서 계산한 이미지 특징값
  • 세션 시간, 횟수 기록

이 정보는 iPhone 안에만 저장됩니다. Apple Watch 앱을 쓰는 경우에는 오늘 할 일 요약(습관 이름, 완료 여부, 연속 일수)이 사용자의 Apple Watch로만 전달됩니다. 앱을 삭제하거나 앱의 마이 → 모든 데이터 삭제를 실행하면 지워집니다.

사용자가 직접 마이 → 백업 내보내기를 실행한 경우에만, 기록이 담긴 백업 파일이 사용자가 고른 위치(예: 파일 앱, iCloud Drive)에 저장됩니다. MOKI는 이 파일을 다른 곳으로 보내지 않습니다.

3. 카메라 사용

카메라는 등록한 물건을 알아보는 용도로만 사용합니다. 카메라 영상은 기기 안에서 실시간으로 분석된 뒤 저장하지 않습니다. 등록할 때 직접 촬영 버튼을 누른 사진만 저장됩니다.

4. 건강 앱 데이터

사용자가 습관을 건강 앱과 연결한 경우에만, 걸음 수·운동 시간·마음챙김 시간을 읽기만 합니다. 읽은 값은 목표를 넘었는지 판단하는 데만 쓰고, 값 자체는 저장하거나 기기 밖으로 보내지 않으며, 광고나 마케팅에 쓰지 않습니다. 목표를 넘은 날에는 "건강 앱으로 채움"이라는 완료 기록만 남고, 이 완료 기록은 백업 파일에 포함될 수 있습니다. 건강 앱에 데이터를 쓰지 않습니다. 권한은 설정 → 건강 → 데이터 접근 및 기기에서 언제든 끌 수 있습니다.

5. 알림

사용자가 정한 습관 알림, 휴식 타이머 종료, 단계별 루틴의 다음 단계를 알려 주기 위해 기기 안에서 예약하는 로컬 알림만 사용합니다. 알림 내용은 기기 밖으로 보내지 않습니다. 알림은 설정 → MOKI → 알림에서 언제든 끌 수 있습니다.
